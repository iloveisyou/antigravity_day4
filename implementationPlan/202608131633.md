# Implementation Plan - Step 19: 실시간 채팅 메시지 구독 및 불러오기 구현

`harness.md`의 **step19** 요구사항에 따라, 페이지/채팅 접속 시 기존 채팅 메시지 목록을 Supabase DB에서 조회해 표시하고, Realtime `INSERT` 이벤트를 구독하여 실시간으로 메시지를 화면에 추가 렌더링하도록 구현합니다.

## User Review Required

> [!IMPORTANT]
> - Supabase `messages` 테이블의 컬럼명 명세에 맞춰 처리합니다:
>   - `content`: 메시지 텍스트
>   - `user_email` 또는 `users_email`: 보낸 사람 이메일 (이메일 주소 중 `@` 앞 닉네임만 표시)
>   - `created_at`: 메시지 작성 일시
> - Supabase Realtime 채널 구독:
>   ```javascript
>   window.supabaseClient
>     .channel('public:messages')
>     .on('postgres_changes', { event: 'INSERT', schema: 'public', table: 'messages' }, (payload) => {
>       appendChatMessage(payload.new);
>     })
>     .subscribe();
>   ```
