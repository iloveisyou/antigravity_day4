# Implementation Plan - Step 21-1: 프로필 사진 관리 UI 구현

실시간 채팅 화면 상단에 사용자의 프로필 관리 UI 영역을 추가하고, 프로필 이미지 선택 동작을 구현합니다.

## 작업 내용

1. **HTML ([index.html](file:///Users/iloveisyou/Desktop/Project/AI/antigravity/day4/index.html))**
   - 실시간 채팅 창(`chat-window`) 상단에 `chat-profile-section` 프로필 섹션 배치
   - 원형 사용자 아바타 컨테이너(`profile-avatar-container`) 생성
   - 프로필 이미지가 없을 때 노출될 기본 사람 아이콘 SVG(`user-profile-default`) 및 이미지 태그(`user-profile-img`) 구성
   - 사진 변경 텍스트 버튼(`btn-change-profile-photo`) 및 파일 선택 인풋(`profile-file-input`) 추가

2. **CSS ([style.css](file:///Users/iloveisyou/Desktop/Project/AI/antigravity/day4/style.css))**
   - 프로필 섹션 스타일링 및 원형 아바타 호버 효과 적용
   - 기본 사람 아이콘 스타일 및 사진 변경 버튼 호버 액션 구현

3. **JavaScript ([app.js](file:///Users/iloveisyou/Desktop/Project/AI/antigravity/day4/app.js))**
   - 프로필 이미지 원형 태그 및 '사진 변경' 버튼 클릭 시 내 컴퓨터의 이미지 선택 파일 창(`profile-file-input`)이 열리도록 연동

## 검증 계획
- 브라우저에서 채팅 창을 열어 상단 프로필 섹션과 원형 프로필 영역, '사진 변경' 버튼 UI 표시 확인
- 아바타 영역 및 '사진 변경' 버튼 클릭 시 파일 탐색기(파일 선택 창)가 정상적으로 오픈되는지 확인
