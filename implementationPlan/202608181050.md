# Implementation Plan - Step 21-2: 프로필 사진 업로드 및 프로필 정보 업데이트

사용자가 선정한 이미지를 Supabase Storage `avatars` 버킷에 업로드하고, 공개 URL을 유저 메타데이터(`avatar_url`)에 반영하여 상단 프로필 및 채팅 메시지와 연동합니다.

## 작업 내용

1. **Storage 업로드 & URL 획득 (`app.js`)**
   - 사용자가 이미지 파일을 선택하면 `supabase.storage.from('avatars').upload('[user_id]/avatar.[ext]', file, { upsert: true })` 호출
   - 업로드 성공 후 `supabase.storage.from('avatars').getPublicUrl(filePath)`를 사용해 공개 URL 획득

2. **Supabase Auth 사용자 메타데이터 업데이트 (`app.js`)**
   - `supabase.auth.updateUser({ data: { avatar_url: publicUrl } })` 함수로 사용자 프로필 사진 메타데이터 동기화

3. **프로필 UI 및 채팅 메시지 연동 (`app.js`, `style.css`)**
   - 프로필 변경 즉시 채팅 상단의 원형 프로필 이미지를 새 사진 URL로 갱신
   - 로그인 상태(세션) 초기화 및 Auth 상태 변경 시 `user_metadata.avatar_url`을 읽어 상단 프로필 실시간 반영
   - 메시지 전송 시 `avatar_url`을 함께 저장하고, 채팅 메시지 노출 시 작성자 프로필 사진 아바타가 함께 나타나도록 연결

## 검증 계획
- 브라우저에서 '사진 변경' 클릭 후 이미지 파일 업로드 테스트
- 업로드 성공 시 Alert 표시 및 채팅 상단 프로필 이미지 즉시 변경 확인
- 메시지 입력 후 전송 시 메시지 옆에 유저의 프로필 사진이 제대로 표시되는지 확인
