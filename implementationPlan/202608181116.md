# Implementation Plan - Step 22-1: 채팅 UI 최적화 및 이미지 첨부 버튼 추가

실시간 채팅 창의 상단 프로필 영역을 제목 라인에 통합하여 메시지 표시 공간을 극대화하고, 메시지 입력창 하단에 클립 모양의 이미지 첨부 버튼 및 아이콘 스타일 전송 버튼을 추가합니다.

## 작업 내용

1. **HTML ([index.html](file:///Users/iloveisyou/Desktop/Project/AI/antigravity/day4/index.html))**
   - 기존의 독립적 프로필 섹션(`#chat-profile-section`)을 삭제하고, 프로필 사진 이미지/기본 아이콘 및 '사진 변경' 미니 버튼을 `.chat-header` 제목 라인에 컴팩트하게 통합
   - 메시지 입력 폼(`#chat-form`)의 '전송' 버튼을 종이비행기 아이콘 버튼으로 교체
   - '전송' 버튼 왼쪽에 클립 아이콘 이미지 첨부 버튼(`#chat-attach-btn`) 및 숨김 파일 입력을 추가 (`#chat-image-input`)

2. **CSS ([style.css](file:///Users/iloveisyou/Desktop/Project/AI/antigravity/day4/style.css))**
   - 헤더 라인에 맞춘 32px 콤팩트 프로필 아바타(`.header-avatar`) 및 미니 사진 변경 버튼(`.btn-change-photo-mini`) 스타일 추가
   - 클립 아이콘 첨부 버튼(`.chat-action-icon-btn`) 및 종이비행기 전송 버튼(`.chat-send-icon-btn`) 스타일 작성

3. **JavaScript ([app.js](file:///Users/iloveisyou/Desktop/Project/AI/antigravity/day4/app.js))**
   - 헤더 내 프로필 아바타/사진 변경 클릭 이벤트 바인딩 유지
   - 클립 아이콘 버튼(`#chat-attach-btn`) 클릭 시 이미지 선택창(`#chat-image-input`)이 열리도록 연동

## 검증 계획
- 채팅창 상단 제목 라인에 아바타와 '사진 변경' 미니 버튼이 깔끔하게 재배치되었는지 확인
- 메시지 목록 표시 영역 공간 확보 확인
- 입력창 하단의 클립 아이콘 클릭 시 내 컴퓨터에서 이미지를 선택할 수 있는 파일 선택창이 오픈되는지 확인
