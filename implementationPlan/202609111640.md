# Step 22-2: 채팅 이미지 첨부 업로드 및 렌더링 구현 계획서

## 개요
`harness.md`의 **Step 22-2** 요구사항에 맞춰 사용자가 채팅창에서 클립 버튼을 누르고 이미지를 선택했을 때 Supabase `chat-images` 버킷에 업로드하고, 공개 URL을 `[image](URL)` 포맷으로 `messages` 테이블에 저장 및 렌더링하는 기능을 구현합니다. 또한 이미지를 정상적으로 로드하지 못할 경우를 대비한 `onerror` 대처 로직과 CSS 스타일을 보완합니다.

## 변경 계획

### 1. JavaScript (`app.js`)
- `#chat-image-input` 파일 선택 이벤트 핸들러 구현
  - 로그인 세션 검증 및 이미지 파일 타입 체크
  - 고유 파일 경로(`[user_id]/[timestamp]_[filename]`) 생성 후 `chat-images` 버킷 업로드
  - `getPublicUrl`을 호출하여 공개 URL 확보
  - `messages` 테이블에 `[image](publicUrl)` 형식으로 메시지 전송
- `appendChatMessage(msg)` 메시지 파서 & 렌더러 보완
  - `msg.content`가 `^[image]\((.*?)\)$` 형식인지 검사
  - 이미지 메시지인 경우 `.message-bubble` 내에 `<img>` 요소 생성 및 삽입
  - `onerror` 처리: 이미지를 로드하지 못할 시 대체 안내 텍스트/경고 UI로 전환
  - `onload` 처리: 이미지 로딩 완료 후 채팅 스크롤 하단 이동

### 2. CSS (`style.css`)
- `.chat-msg-image`: 메시지 버블 내 이미지 스타일 (최대 너비 220px, 둥근 앵커 모서리, 줌/미리보기 호버 효과)
- `.chat-img-error`: 이미지 로드 실패 시 나타나는 에러 박스 스타일

## 검증 계획
1. 클립 버튼 클릭 후 이미지 파일 선택 시 `chat-images` 버킷에 정상 업로드 확인
2. Supabase `messages` 테이블에 `[image](https://...)` 형태 행 추가 검증
3. 채팅창에 텍스트 대신 이미지가 올바르게 렌더링되는지 확인
4. 잘못된 URL 또는 이미지 로드 실패 시 대체 UI 노출 확인
