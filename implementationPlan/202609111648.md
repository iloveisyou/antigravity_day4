# Step 22-2 버그 수정: 배포 환경 이미지 업로드 및 RLS/버킷 설정 보완 계획서

## 원인 분석
1. **Supabase Storage `upsert: true` 권한 이슈**: `chat-images` 버킷에 `UPDATE` RLS 정책이 없거나 RLS check 시 `upsert: true` 옵션으로 인해 RLS 403(Policy Violation) 에러가 발생할 수 있습니다.
2. **파일명 파싱 및 경로 안전성**: 파일명에 특수문자나 한글이 포함된 경우 치환 과정 문제 해결. `[userId]/[timestamp].[ext]` 구조로 단순화하여 예외 방지.
3. **Supabase Storage 버킷 Public 설정 및 SQL 정책 보완**: `chat-images` 버킷의 `UPDATE` 정책 추가 및 Supabase Dashboard 안내 조치 필요.
4. **에러 로깅 및 정규식 개선**: `appendChatMessage`의 정규식 `.trim()` 적용 및 업로드 에러 시 세부 메세지 출력.

## 변경 계획
- **`app.js`**:
  - 파일 업로드 시 `upsert: false`로 변경하여 `INSERT` 전용 RLS 정책과 일치시킴.
  - 파일 저장 경로를 `${userId}/${Date.now()}.${fileExt}`로 단순화하여 파일명 특수문자 이슈 제거.
  - `msg.content.trim()` 정규식으로 이미지 메시지 파싱 유연화.
  - 상세 에러 출력 (`err.message || err.error_description || JSON.stringify(err)`).
- **`supabase_storage_policies.sql`**:
  - `chat-images` 버킷에 `UPDATE` 정책 추가 및 기존 SQL 가이드 명확화.

## 검증 계획
- 코드 수정 후 commit/push하여 배포 환경 빌드 유도 및 Supabase 버킷 확인 가이드 제공.
