- **목적**: 장기 미사용 시 발생하는 Supabase의 자동 일시중지(Pause) 및 Upstash Redis의 데이터 소멸을 방지하기 위해 365일 무중단 자동 헬스체크 시스템 구축

## 1. 아키텍처 설계

```
                 [GitHub Actions 클라우드 러너]
                 (매주 월, 목 한국시간 09:00 자동 실행)
                               │
                               ▼
               [GET https://antigravity-day4.vercel.app/api/keep-alive]
                               │
            ┌──────────────────┴──────────────────┐
            ▼                                     ▼
     [Supabase DB]                           [Upstash Redis]
(SELECT count 쿼리 1회 실행)                 (PING 명령어 1회 실행)
 ──► 활동(Activity) 기록                    ──► 활동(Activity) 기록
 ──► 자동 일시중지(Pause) 원천 차단          ──► 인스턴스 자동 소멸 방지
```

이중 안전망(Dual Protection):
1. **GitHub Actions 스케줄러**: `.github/workflows/keep-alive.yml` (주 2회 월·목 자동 실행, 수동 실행 지원)
2. **Vercel Cron 스케줄러**: `vercel.json` (Vercel 자체 주 2회 스케줄러 탑재)
