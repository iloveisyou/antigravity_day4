# Walkthrough - Step 18: 메시지 전송 기능 구현 완료

`harness.md`의 **step18** 명세에 따라, 사용자가 입력한 메시지를 Supabase `messages` 테이블에 저장하는 전송 기능을 구현했습니다.

## 주요 변경 사항

### 1. Supabase Messages Table Insert (`app.js`)
- `chatForm` 제출 (`submit` 이벤트 / 엔터 입력 포함) 시 현재 로그인된 사용자의 이메일(`user_email`)과 입력 메시지(`content`)를 Supabase `messages` 테이블로 전송합니다.
- `supabaseClient.from('messages').insert({ content: messageText, user_email: userEmail })` 메서드 호출
- 전송 성공 시 입력창(`chatInput`)의 내용을 깨끗하게 초기화(비움)합니다.
