# Walkthrough - Step 19: 실시간 메시지 구독 및 불러오기 구현 완료

`harness.md`의 **step19** 명세에 따라, Supabase Realtime 구독 기능 및 기존 채팅 메시지 불러오기 기능을 성공적으로 구축했습니다.

## 주요 변경 사항

### 1. 기존 메시지 목록 조회 (`fetchChatMessages`)
- 로그인 성공 시 Supabase `messages` 테이블에서 `created_at` 오름차순으로 모든 메시지를 가져와 렌더링합니다.
- 작성자 이메일(`user_email` / `users_email`)의 `@` 앞부분 닉네임을 추출하여 표출합니다.
- 작성자가 현재 로그인한 사용자 본인일 경우 오른쪽 `.outgoing` 말풍선, 타인일 경우 왼쪽 `.incoming` 말풍선 및 닉네임 라벨을 생성합니다.

### 2. Supabase Realtime 구독 (`subscribeChatRealtime`)
- `window.supabaseClient.channel('messages').on('postgres_changes', { event: 'INSERT', schema: 'public', table: 'messages' }, callback).subscribe()` 연동을 구현했습니다.
- 실시간으로 신규 메시지가 추가(`INSERT`)되면 중복 체크 후 자동으로 채팅 목록 하단에 렌더링하고 최하단으로 자동 스크롤시킵니다.
