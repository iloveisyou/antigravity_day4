# Walkthrough - Step 20: Supabase 스토리지 보안 정책 SQL 작성

`harness.md`의 **step20** 요구사항에 따른 Supabase Storage `avatars` 및 `chat-images` 버킷 RLS 보안 정책 SQL 생성을 완료했습니다.

## 주요 내용 (`supabase_storage_policies.sql`)

### 1. `avatars` 버킷 보안 정책
- **SELECT (조회)**: 누구나 프로필 이미지를 볼 수 있도록 Public Read 허용
- **INSERT (생성)**: 로그인한 사용자(`authenticated`)가 자신의 사용자 ID로 된 폴더(`[user_id]/filename`)에만 프로필 파일 업로드 허용
- **UPDATE (수정)**: 로그인한 사용자(`authenticated`)가 자신의 사용자 ID 폴더 내 파일만 수정 허용

### 2. `chat-images` 버킷 보안 정책
- **SELECT (조회)**: 누구나 채팅 이미지를 볼 수 있도록 Public Read 허용
- **INSERT (생성)**: 로그인한 사용자(`authenticated`)라면 누구나 채팅 이미지를 업로드할 수 있도록 허용

## 사용 방법
Supabase 대시보드 -> **SQL Editor** -> **New Query**에 생성된 `supabase_storage_policies.sql` 전체 내용을 복사하여 **Run**을 실행하시면 됩니다.
