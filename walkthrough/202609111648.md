# Walkthrough - 배포 환경 이미지 업로드 이슈 조치 결과

배포 사이트에서 채팅 이미지 첨부가 정상 작동하지 않던 원인을 분석하고 보완 조치를 완료했습니다.

## 주요 수정 사항

1. **`app.js` 이미지 업로드 및 예외 처리 강화**
   - **`upsert: false`로 변경**: RLS `UPDATE` 정책 미등록 상태에서 `upsert: true` 호출 시 발생하는 403 (Row-Level Security Violation) 예외를 방지했습니다.
   - **파일 저장 경로 단순화**: `${userId}/${Date.now()}.${fileExt}` 경로로 변경하여 한글/특수문자 파일명에 따른 저장 실패 문제를 예방했습니다.
   - **정규식 및 상세 에러 로깅**: `msg.content.trim()` 매칭 적용 및 실패 시 `err.message`, `err.error_description`을 명확히 alert 및 콘솔에 남기도록 보완했습니다.

2. **`supabase_storage_policies.sql` 정책 보완**
   - `chat-images` 버킷용 `UPDATE` RLS 정책을 추가하여 Supabase 대시보드에서 적용 가능한 SQL을 동기화했습니다.

## Supabase 대시보드 필수 점검 사항 (사용자 확인 항목)
- [ ] Supabase Dashboard > Storage > `chat-images` 버킷이 **Public Bucket**으로 설정되어 있는지 확인
