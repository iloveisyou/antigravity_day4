## 1. 개요 및 원인 분석

1. **에러 원인 1 (브라우저 유효하지 않은 토큰 캐싱)**
   - 브라우저 로컬 저장소(`localStorage`)에 과거 발급되었거나 만료된 세션 토큰이 캐시되어 페이지 기동 시마다 `/api/history`로 전송됨.
   - 프론트엔드가 401(`Unauthorized: Invalid token`) 응답을 수신했을 때 세션을 정리하지 않고 화면에 빨간 에러 메시지만 띄워 사용자가 에러 화면에 갇힘.
2. **에러 원인 2 (Vercel 환경변수 레거시 DB 잔존)**
   - Vercel 프로덕션 환경변수에 과거 105일 전에 설정되었던 구형 레거시 Supabase(`ylhbaiolxexzkuinsprj`) 정보가 등록되어 있어 백엔드 서버리스 함수의 토큰 검증 시 충돌 발생.
3. **에러 원인 3 (로컬 개발 서버 프로세스 모듈 불일치)**
   - 로컬 `vercel dev`가 `package.json`의 `"type": "module"` 추가 이전에 기동되어 모듈 로더 오류로 500 에러 발생.

- `/api/history` 및 `/api/analyze`에서 401(토큰 만료/무효) 수신 시:
