## 1. 개요 및 원인 분석

### 현상
- 로컬 개발 서버(`http://localhost:3000`)에서 정상 계정으로 로그인 성공 후, 1초 만에 다시 로그인 화면으로 튕겨나가는 현상 발생.

### 근본 원인
1. **`.env` 파일 내 구형 키 잔존**:
   - 로컬의 `.env` 파일에 소멸된 옛날 Supabase(`ylhbaiolxexzkuinsprj`) 정보가 남아있었음.
2. **JWT 키 필터링 결함**:
   - `api/_lib/supabase.js`가 `!key.includes('ylhbaiolxexzkuinsprj')`로 평문 비교를 수행했으나, JWT 토큰 특성상 payload가 Base64로 인코딩되어 있어 평문이 포함되지 않음.
   - 이로 인해 옛날 키가 필터링을 통과하여 신규 URL(`qzbkalpmjjfzroenmoyi`)과 결합됨.
3. **`401 Invalid API key` 및 프론트엔드 강제 로그아웃**:
   - 신규 URL과 구형 키 조합으로 인해 Supabase가 401(Invalid API key)을 반환함.
   - 프론트엔드(`app.js`)는 401을 받으면 즉시 `signOut()`을 실행하고 로그인 화면으로 전환하도록 되어 있어, 로그인 직후 무조건 로그인 폼으로 튕겨나갔던 것임.
4. **어제 기동된 구형 dev 프로세스(PID 10572)**:
   - 어제 4:25PM에 기동된 프로세스가 종료되지 않고 메모리에 구형 모듈을 물고 있었음.
